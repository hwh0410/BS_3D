## 資料依據與限制
- 全區配置圖第1頁：基地輪廓和設備相對位置以圖像手動近似對位，未使用完整向量座標校準；局部公尺座標非測量座標。
- 新版平立面圖第1頁：兩棟建築平面尺寸近似採用12.15×12及12×5 m；屋高、屋頂、門窗暫為示意。
- 使用者指定四座相鄰40呎貨櫃；暫用標準外廓12.192×2.438×2.591 m，實際高度與間距未確認。採購表舊編號 R-1001A/B/C 不應視為四槽正式編號。
- 採購表靜設備：D-1004A/B PE 50T，直徑3100 mm、高7456 mm；第三個圓形設備身分待確認。BD-1001 兩只，直徑2500 mm、長10000 mm，未定位。其他未定位設備列於側欄。
- EASM ZIP 可解封裝，包含 HSF V19.10 eModel、materials.xml、scene.xml、preview.jpg；尚未解碼網格。建議向設計端索取 GLB 或 STEP/原始 SLDASM 與零件檔，轉換至 GLB 後本機匯入。
- 地形目前平坦、道路未精確重建、概念氣管預設隱藏。無施工或安全決策用途。未上傳原始工程資料。
